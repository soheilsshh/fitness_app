مستند مرجع برای **مدیران پنل ادمین** — نقشه صفحات، اجزای رابط کاربری، و تمام مسیرهایی که کاربر یا ادمین طی می‌کند.

| مسیر | صفحه | مخاطب |

| بلوک UI | محتوا |
|---------|--------|

- تکمیل = تماشا/دکمه تکمیل → قبولی کوییز → API `complete` → XP + آنلاک روز بعد

## ۴. فلوهای کاربر (User Flows)

### فلو A — بازدیدکننده → ثبت‌نام

```
لندینگ (/)
  → اسکرول / کلیک «شروع رایگان» / ریل سفر
  → پر کردن فرم (نام، نام‌خانوادگی، موبایل)
  → POST /api/register
  → ذخیره userPhone در localStorage
  → toast موفقیت (یا «خوش برگشتی» اگر existing)
  → /register/thank-you
  → (۵ ثانیه یا دکمه) → /videos
```

**نکته:** شماره با `0` یا بدون `+98` به `+98...` نرمال می‌شود.  
**پس‌زمینه:** SMS خوش‌آمد / follow-up طبق الگوهای `config.yaml` زمان‌بندی می‌شود.

### فلو B — کاربر برگشتی (قبلاً ثبت‌نام کرده)

```
لندینگ با userPhone موجود
  → دکمه شناور «ادامه یادگیری»
  → /videos (پیشرفت از API بارگذاری می‌شود)
```

یا ثبت‌نام مجدد با همان شماره → پاسخ `existing` → همان مسیر Thank You.

### فلو C — تماشا و پیشرفت در آکادمی

```
/videos
  → GET /api/videos + GET /api/progress?phone=...
  → انتخاب جلسه باز
  → پخش ویدیو
  → پایان ویدیو یا دکمه «تکمیل» → باز شدن SessionQuiz
  → پاسخ به ۳ سؤال
       ├─ کمتر از ۳ درست → نمایش نتیجه + «تلاش مجدد»
       └─ ۳/۳ درست → POST /api/videos/:id/complete
            → XP اضافه می‌شود · جلسه completed · روز بعد unlocked
            → toast با مقدار XP
```

### فلو D — باز کردن جلسه بعدی با آزمون

```
جلسه N → کوییز ۳/۳
  → POST /api/videos/N/complete
  → بک‌اند روز N+1 را unlocked می‌کند
  → ریل مأموریت روز بعد را باز نشان می‌دهد
```

### فلو E — خروج کاربر

```
/videos → آیکون خروج
  → پاک شدن userPhone
  → هدایت به /
```

### فلو F — اتمام پنجره ۷۲ ساعته

تایمر از اولین بازدید `/videos` شروع می‌شود. بعد از اتمام، UI شمارش معکوس به حالت منقضی می‌رود (دسترسی به محتوا همچنان وابسته به منطق فعلی صفحه است؛ برای پشتیبانی به کاربران منقضی‌شده از پنل آمار/لیست استفاده کنید).

## ۵. پنل ادمین — UI و فلوها

### ۵.۱ ورود `/admin/login`

| UI | توضیح |
|----|--------|
| کارت ورود | لوگو فیتینو + عنوان «پنل مدیریت چالش ۲۱ روزه» |
| فیلد نام کاربری | اجباری |
| فیلد رمز | اجباری |
| پیام خطا | در صورت اعتبارنامعتبر |
| دکمه ورود | `POST /api/admin/login` → ذخیره توکن → `/admin` |

اگر توکن از قبل موجود باشد، مستقیم به `/admin` می‌رود.  
اعتبارنامه‌ها در `backend/config/config.yaml` بخش `admin` تعریف شده‌اند.

### ۵.۲ داشبورد `/admin`

بدون توکن → ریدایرکت به `/admin/login`.  
۴۰۱ از API → پاک شدن توکن و برگشت به لاگین.

**دیتابیس:** فقط دیتابیس اختصاصی اپ ۲۱day (`config.yaml` → `db.name`) — مستقل از Live / فیتینوی اصلی.

#### هدر
- برند + عنوان پنل + یادآوری DB اختصاصی
- دکمه بروزرسانی آمار
- دکمه **خروج** → `POST /api/admin/logout` + پاک کردن توکن

#### تب‌ها
1. **آمار و قیف** — کارت‌ها + نمودار + قیف ۲۱روزه
2. **کاربران** — جدول + جست‌وجو + CSV
3. **راهنما** — فلو ادمین/کاربر + چک‌لیست پشتیبانی

#### کارت‌های آمار (۵ تایی)

| کارت | معنی |
|------|------|
| کل ثبت‌نام‌ها | مجموع کاربران + hint «امروز» |
| نرخ شروع | درصد کسانی که حداقل یک ویدیو شروع/درگیر شده‌اند + تعداد شروع‌نکرده |
| نرخ تکمیل دوره | درصد کسانی که همه جلسات را کامل کرده‌اند |
| میانگین پیشرفت | میانگین درصد پیشرفت کاربران |
| ثبت‌نام این هفته | تعداد ثبت‌نام ۷ روز اخیر |

#### نمودار ثبت‌نام روزانه
- میله‌ای · ۱۴ روز اخیر · از `registrations_by_day`

#### قیف پیشرفت چالش
1. مرحله **ثبت‌نام** (۱۰۰٪ عرض)
2. به ازای هر ویدیو: «رسیده / کامل» نسبت به کل ثبت‌نام‌ها

#### جدول کاربران
| ستون | فیلد |
|------|------|
| نام | first + last |
| شماره | phone |
| تاریخ ثبت‌نام | created_at |
| پیشرفت | completed/total + درصد |
| XP | total_points |
| سطح | level |
| آخرین فعالیت | last_activity |

**تعامل‌ها:**
- جست‌وجوی نام یا شماره (debounce ~۳۵۰ms)
- صفحه‌بندی ۱۵تایی
- **خروجی CSV** → دانلود لیست کاربران (`GET /api/admin/users/csv`)

### ۵.۳ فلو ادمین

```
/admin/login → وارد کردن یوزر/پس → توکن
  → /admin
  → مشاهده آمار / قیف / نمودار
  → جست‌وجو یا ورق زدن لیست کاربران
  → در صورت نیاز: خروجی CSV
  → خروج
```

## ۶. API مرتبط (خلاصه برای پشتیبانی)

| متد | مسیر | نقش |
|-----|------|-----|
| POST | `/api/register` | ثبت‌نام کاربر |
| GET | `/api/videos` | لیست ۲۱ جلسه + کد و XP |
| GET | `/api/progress` | پیشرفت کاربر با phone |
| POST | `/api/videos/:id/complete` | تکمیل بعد از کوییز |
| POST | `/api/videos/:id/unlock` | آنلاک دستی (legacy؛ مسیر اصلی از complete است) |
| POST | `/api/admin/login` | ورود ادمین |
| POST | `/api/admin/logout` | خروج ادمین |
| GET | `/api/admin/stats` | آمار داشبورد |
| GET | `/api/admin/users` | لیست صفحه‌بندی‌شده |
| GET | `/api/admin/users/csv` | خروجی CSV |

پورت پیش‌فرض بک‌اند: **8081** (`server_port` در `config.yaml`).

## ۷. اقتصاد XP (برای خواندن آمار سطح)

| روزها | XP تقریبی هر جلسه |
|-------|-------------------|
| بیشتر روزها | ۱۰ |
| روز ۷ و ۱۴ | ۱۵ |
| روز ۲۱ | ۲۵ |

جمع تقریبی کل مسیر ≈ **۲۳۵ XP**.  
سطح در پنل از پیشرفت بک‌اند می‌آید (`level` / `total_points`).

**گیت XP:** بدون قبولی کامل کوییز (۳/۳)، `complete` صدا زده نمی‌شود و XP ثبت نمی‌شود.

## ۸. SMS خودکار (پس‌زمینه — بدون UI ادمین در این اپ)

الگوها در `config.yaml` → `patterns`:

| الگو | کاربرد تقریبی |
|------|----------------|
| `registration` | خوش‌آمد بعد از ثبت‌نام |
| `followup*_3h` / `*_15h` | یادآوری‌های زمان‌بندی‌شده |
| `complete*` | پیام‌های مرتبط با تکمیل مراحل |

ادمین ۲۱روز **فعلاً UI جدا برای ویرایش SMS ندارد**؛ مانیتورینگ از طریق آمار ثبت‌نام، نرخ شروع، و آخرین فعالیت کاربران انجام می‌شود.

## ۹. چک‌لیست سریع پشتیبانی ادمین

| مشکل کاربر | کجا چک کنید |
