# پنل مدیریتی وبینار - راهنمای استفاده

## 🎯 ویژگی‌ها

پنل مدیریتی وبینار یک سیستم کامل برای نظارت و مدیریت وبینار شماست که شامل:

### ✅ آمار کلی
- **تعداد ثبت‌نام‌ها**: تعداد کل کاربرانی که در وبینار ثبت‌نام کرده‌اند
- **تعداد کلیک روی لینک**: تعداد کاربرانی که روی لینک وبینار کلیک کرده‌اند
- **تعداد بینندگان**: تعداد کاربرانی که وبینار را تماشا کرده‌اند
- **میانگین زمان تماشا**: میانگین مدت زمان تماشای وبینار (به دقیقه)
- **نرخ تبدیل**: نرخ تبدیل کلیک به تماشا و ثبت‌نام به تماشا
- **عدم تماشا**: تعداد کاربرانی که ثبت‌نام کرده‌اند اما وبینار را تماشا نکرده‌اند

### 📊 لیست کاربران
- نمایش کامل لیست کاربران ثبت‌نام شده
- نمایش وضعیت تماشا (تماشا کرده/نکرده)
- نمایش مدت زمان تماشا برای هر کاربر

### 📥 خروجی اکسل
- **خروجی بینندگان**: فایل اکسل شامل کاربرانی که وبینار را تماشا کرده‌اند (با مدت زمان تماشا)
- **خروجی غیر بینندگان**: فایل اکسل شامل کاربرانی که ثبت‌نام کرده‌اند اما وبینار را تماشا نکرده‌اند

## 🔐 اطلاعات ورود پیش‌فرض

**⚠️ مهم**: پس از اولین ورود، حتماً رمز عبور را تغییر دهید!

- **نام کاربری**: `admin`
- **رمز عبور**: `admin123`

## 🚀 نحوه استفاده

### 1. دسترسی به پنل

برای دسترسی به پنل مدیریتی:
1. به آدرس `/admin/login` بروید
2. نام کاربری و رمز عبور را وارد کنید
3. روی دکمه "ورود" کلیک کنید

### 2. مشاهده آمار

پس از ورود، به صفحه داشبورد هدایت می‌شوید که شامل:
- **کارت‌های آمار**: نمایش آمارهای کلیدی
- **لیست کاربران**: جدول کامل کاربران با جزئیات

### 3. دریافت خروجی اکسل

برای دریافت خروجی اکسل:
1. روی دکمه "خروجی اکسل - بینندگان" کلیک کنید (برای دریافت لیست کاربرانی که وبینار را تماشا کرده‌اند)
2. یا روی دکمه "خروجی اکسل - غیر بینندگان" کلیک کنید (برای دریافت لیست کاربرانی که ثبت‌نام کرده‌اند اما تماشا نکرده‌اند)

فایل CSV دانلود می‌شود و می‌توانید آن را در Excel باز کنید.

## 🔒 امنیت

### تغییر رمز عبور

برای تغییر رمز عبور پیش‌فرض، باید مستقیماً در پایگاه داده تغییر دهید:

```sql
-- هش کردن رمز عبور جدید (مثال: newpassword123)
-- از bcrypt برای hash کردن استفاده کنید
UPDATE admin_users SET password = '$2a$10$HASHED_PASSWORD' WHERE username = 'admin';
```

**یا** می‌توانید از تابع `HashPassword` در کد Go استفاده کنید.

### JWT Token

پس از ورود موفق، یک JWT token ایجاد می‌شود که:
- مدت اعتبار: 24 ساعت
- در localStorage ذخیره می‌شود
- برای دسترسی به API های admin استفاده می‌شود

## 📡 API Endpoints

### Public Endpoints

#### ثبت کلیک روی لینک
```
POST /api/track/click
Body: { "phone": "09123456789" }
```

#### ثبت شروع تماشا
```
POST /api/track/view
Body: { 
  "phone": "09123456789",
  "view_start_time": "2024-01-01T19:30:00Z"
}
```

#### به‌روزرسانی زمان تماشا
```
POST /api/track/view-time
Body: { 
  "phone": "09123456789",
  "view_minutes": 45
}
```

### Protected Endpoints (نیاز به Authentication)

#### دریافت آمار
```
GET /api/admin/stats
Headers: { "Authorization": "Bearer <token>" }
```

#### دریافت لیست کاربران
```
GET /api/admin/users
Headers: { "Authorization": "Bearer <token>" }
```

#### خروجی اکسل - بینندگان
```
GET /api/admin/export/viewers
Headers: { "Authorization": "Bearer <token>" }
```

#### خروجی اکسل - غیر بینندگان
```
GET /api/admin/export/non-viewers
Headers: { "Authorization": "Bearer <token>" }
```

## 🗄️ ساختار پایگاه داده

### جدول `webinar_activities`
- **phone**: شماره تماس کاربر
- **activity_type**: نوع فعالیت (click, view_start, view_end, view_update)
- **clicked_at**: زمان کلیک روی لینک
- **view_start_time**: زمان شروع تماشا
- **view_end_time**: زمان پایان تماشا
- **total_view_minutes**: مدت زمان کل تماشا (دقیقه)

### جدول `admin_users`
- **username**: نام کاربری ادمین
- **password**: رمز عبور (hash شده با bcrypt)

## 🔧 تنظیمات

### تغییر JWT Secret

در فایل `backend/controllers/admin_auth.go`:

```go
var jwtSecret = []byte("your-secret-key-change-in-production")
```

**⚠️ مهم**: در محیط production حتماً یک secret key قوی و منحصر به فرد استفاده کنید!

## 📝 نکات مهم

1. **پسورد پیش‌فرض**: حتماً پسورد پیش‌فرض را تغییر دهید!
2. **JWT Secret**: در production یک secret key قوی استفاده کنید
3. **HTTPS**: در production حتماً از HTTPS استفاده کنید
4. **Backup**: به صورت منظم از پایگاه داده backup بگیرید
5. **Logs**: لاگ‌های سیستم را به صورت منظم بررسی کنید

## 🐛 عیب‌یابی

### مشکل در ورود
- چک کنید که پایگاه داده در دسترس است
- چک کنید که کاربر admin ایجاد شده است
- لاگ‌های backend را بررسی کنید

### مشکل در دریافت آمار
- چک کنید که token معتبر است
- چک کنید که در localStorage ذخیره شده است
- اگر token منقضی شده، دوباره وارد شوید

### مشکل در دانلود اکسل
- چک کنید که token معتبر است
- چک کنید که CORS به درستی تنظیم شده است
