# 🔄 سیستم حلقه‌ای و دوره‌ای وبینار

## ✅ تغییرات اعمال شده

سیستم اکنون به صورت **کامل حلقه‌ای و دوره‌ای** کار می‌کند و هر روز به صورت خودکار:

1. ✅ زمان وبینار را به‌روزرسانی می‌کند
2. ✅ استریم را برای روز جدید شروع می‌کند
3. ✅ پیامک‌های یادآوری را ارسال می‌کند
4. ✅ سیستم فروش اتوماتیک را فعال نگه می‌دارد

---

## 📅 چرخه روزانه سیستم

### ۱. ساعت ۰۰:۰۰ (نیمه شب) - به‌روزرسانی زمان وبینار

**کار انجام شده:**
- زمان شروع وبینار برای امروز محاسبه می‌شود
- زمان پایان وبینار برای امروز محاسبه می‌شود
- اگر زمان شروع گذشته باشد، برای فردا تنظیم می‌شود
- وضعیت `IsLive` به `true` تنظیم می‌شود

**کد:**
```go
s.Every(1).Day().At("00:00").Do(func() {
    updateWebinarSchedule(db, cfg)
})
```

### ۲. ساعت ۱۴:۰۰ (۲ بعدازظهر) - ارسال یادآوری اول

**کار انجام شده:**
- پیامک یادآوری برای کاربرانی که از دیروز ۱۷:۰۰ تا امروز ۱۴:۰۰ ثبت‌نام کرده‌اند ارسال می‌شود
- تماس صوتی (Avanak) نیز ارسال می‌شود

**کد:**
```go
s.Every(1).Day().At("14:00").Do(func() {
    // Send 2 PM reminders
})
```

### ۳. ساعت ۱۸:۳۰ (۶:۳۰ عصر) - ارسال یادآوری نهایی

**کار انجام شده:**
- پیامک یادآوری نهایی (۳۰ دقیقه قبل از شروع) برای همه کاربران امروز ارسال می‌شود
- تماس صوتی (Avanak) نیز ارسال می‌شود

**کد:**
```go
s.Every(1).Day().At("18:30").Do(func() {
    // Send 30-min reminders
})
```

### ۴. ساعت ۲۰:۰۰ (همزمان با شروع وبینار) - شروع استریم

**کار انجام شده:**
- استریم ویدیو برای وبینار امروز شروع می‌شود
- کانال RTMP/HLS آماده می‌شود
- کاربران می‌توانند ویدیو را مشاهده کنند

**کد:**
```go
s.Every(1).Day().At("20:00").Do(func() {
    startStreamingForToday(db, cfg)
})
```

**نکته:** زمان شروع استریم دقیقاً همان زمان شروع وبینار است. اگر وبینار ساعت ۲۰:۰۰ شروع می‌شود، استریم هم ساعت ۲۰:۰۰ شروع می‌شود.

### ۵. ساعت ۲۰:۰۰ - شروع وبینار و استریم

**کار انجام شده:**
- وبینار به صورت رسمی شروع می‌شود
- استریم ویدیو همزمان شروع می‌شود
- کاربران می‌توانند ویدیو را مشاهده کنند
- چت زنده فعال می‌شود
- کامنت‌های زمان‌بندی شده شروع به نمایش می‌کنند

### ۶. ساعت ۲۲:۰۰ - پایان وبینار

**کار انجام شده:**
- وبینار به پایان می‌رسد
- استریم متوقف می‌شود
- سیستم برای روز بعد آماده می‌شود

```go
    // شروع استریم با StartFilePublisher
    // آماده کردن کانال RTMP/HLS
}
```

## ✅ مزایای سیستم حلقه‌ای

1. **خودکار:** نیاز به مداخله دستی ندارد
2. **قابل اعتماد:** هر روز در زمان مشخص اجرا می‌شود
3. **مقاوم در برابر خطا:** اگر یک روز خطا رخ دهد، روز بعد دوباره تلاش می‌کند
4. **قابل تنظیم:** زمان‌ها از `config.yaml` خوانده می‌شوند

---

## ⚙️ تنظیمات در config.yaml

```yaml
webinar:
  start_hour: 20    # ساعت شروع (0-23)
  start_minute: 0  # دقیقه شروع (0-59)
  end_hour: 22      # ساعت پایان (0-23)
  duration_minutes: 123  # مدت زمان وبینار
```

**مهم:** زمان شروع استریم دقیقاً همان زمان شروع وبینار است (`start_hour:start_minute`).

## ⚠️ نکات مهم

1. **سرور باید همیشه روشن باشد:** scheduler فقط زمانی کار می‌کند که سرور در حال اجرا باشد
2. **Timezone:** سیستم از timezone `Asia/Tehran` استفاده می‌کند
3. **فایل ویدیو:** فایل `./videos/video1.mp4` باید موجود باشد
4. **دیتابیس:** وبینار باید در دیتابیس وجود داشته باشد (به صورت خودکار ایجاد می‌شود)

## 🐛 عیب‌یابی

### مشکل: استریم شروع نمی‌شود

**بررسی:**
1. لاگ‌های scheduler را چک کنید (باید در زمان شروع وبینار اجرا شود)
2. مطمئن شوید که فایل ویدیو موجود است
3. مطمئن شوید که RTMP server در حال اجرا است
4. بررسی کنید که زمان scheduler با زمان شروع وبینار یکسان است

### مشکل: زمان وبینار به‌روزرسانی نمی‌شود

**بررسی:**
1. لاگ‌های ساعت ۰۰:۰۰ را چک کنید
2. مطمئن شوید که scheduler در حال اجرا است
3. دیتابیس را بررسی کنید

### مشکل: پیامک‌ها ارسال نمی‌شوند

**بررسی:**
1. تنظیمات Melipayamak را چک کنید
2. لاگ‌های scheduler را بررسی کنید
3. مطمئن شوید که `enabled: true` است
